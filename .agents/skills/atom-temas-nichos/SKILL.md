# Banco de Temas, Ganchos y Nichos (`ATOM` + `PuraPrueba`)

1. Si el creador quiere elegir o cambiar de nicho, lee y sigue `ATOM/packs/nichos.md` y actualiza `ATOM/preferencias.md`.
2. Si pide ideas de temas o un número de tema concreto («dame 5 temas», «hazme el tema 37»):
   - Lee `ATOM/packs/100-temas.md` (y para ganchos de desmitificación, consulta también `PuraPrueba/docs-sesion/estrategia_myth_busting_viral.md`).
   - Revisa `ATOM/temas-usados.md` y `PuraPrueba/workspace/output/` para descartar temas ya producidos.
3. Opcionalmente pasa los ganchos candidatos por `node workspace/library/myth-busting/scorecard_hook.mjs` (desde `PuraPrueba/`) para entregarle opciones con puntaje `10/10`.
